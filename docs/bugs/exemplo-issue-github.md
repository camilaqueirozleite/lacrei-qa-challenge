# Exemplo de Issue para GitHub

## Bug

```markdown
## Descrição

Descreva o comportamento atual de forma objetiva.

## Passos para reproduzir

1. Acessar ...
2. Clicar em ...
3. Preencher ...
4. Observar ...

## Resultado atual

O que aconteceu.

## Resultado esperado

O que deveria acontecer.

## Impacto

Baixo | Médio | Alto | Crítico

## Ambiente

- URL:
- Navegador:
- Dispositivo:
- Viewport:

## Evidência

Anexar print ou vídeo.

## Sugestão

Proposta de correção ou mitigação.
```

## Melhoria

```markdown
## Contexto

Explique a oportunidade de melhoria.

## Proposta

Descreva a mudança sugerida.

## Benefício esperado

Explique impacto em usabilidade, acessibilidade, segurança, desempenho ou clareza.

## Critérios de aceite

- Critério 1
- Critério 2
- Critério 3
```
